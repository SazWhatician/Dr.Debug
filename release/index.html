Capabilities

Built for Modern Full-Stack Developers

Traditional browser DevTools are blind to your containers. Dr. Debug unifies host Docker logs, client network requests, and framework state into a single autonomous brain.

🐳

Host Docker Substrate

Streams container stdout/stderr, container lifecycle changes, and health checks over local SSE. No Docker plugins needed.

🌐

Causal Topology DAG

Connects backend 504 timeouts to downstream React unhandled rejection nodes via temporal and semantic graph correlation.

🧠

Re-Act AI Engine

Autonomous multi-turn investigation using Groq LPU, OpenAI, Anthropic, or on-device LiteRT.js with zero server roundtrips.

🛡️

Zero-Leak Shadow DOM

Rendered inside an isolated Shadow Root `#dr-debug-root`. 100% CSS immune from your application's Tailwind or Bootstrap styles.

Quickstart

Ready in Under 30 Seconds

No complicated cloud accounts. No telemetry tracking. Runs completely local on your machine.

1

Download & Unzip

Download dr-debug-extension.zip and extract it anywhere on your computer.

2

Load into Chrome

Open chrome://extensions, enable Developer Mode, and click "Load Unpacked".

3

Connect Host Docker

Run npx @dr-debug/mcp or double-click start-docker-bridge.bat inside the folder.
