The loop is real: on every turn the agent re-reads the live buffers, and only calls a tool when there is unexamined evidence behind it. With empty buffers it reports an empty session rather than inventing one. The local engine does this deterministically with no API key; picking Groq or OpenAI hands the same tools to an LLM instead.
