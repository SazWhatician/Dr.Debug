Frequently Asked Questions

Straight answers on pairing Dr. Debug with Google Antigravity, Claude Code, and your local development stack.

Standard AI coding assistants burn thousands of tokens blindly guessing UI bugs from static screenshots. Dr. Debug intercepts raw browser runtime exceptions, network request bodies, and component stacks into deterministic <debug_state> XML. Antigravity parses this structured context to pinpoint and edit the exact lines in your workspace immediately.

Dr. Debug runs a local Model Context Protocol (MCP) daemon on port 9229 (started with npx @dr-debug/mcp). Claude Code connects via standard JSON-RPC tools (drdebug_inspect_error, drdebug_inspect_request) to query your live browser tab without manual copy-pasting.

No. Dr. Debug is 100% local-first. All telemetry—console logs, network bodies, memory footprints, and Docker logs—stays strictly inside your browser session and your local machine. No tracking, analytics, or external servers are contacted.

Download dr-debug-extension.zip, extract the archive, open chrome://extensions in Chrome, toggle on Developer mode in the top-right corner, and click "Load unpacked". The Dr. Debug tab will immediately appear inside Chrome DevTools (F12).

The bridge daemon runs safe, 100% read-only Docker CLI commands (docker version, docker ps, docker logs -f) to stream container stdout/stderr over local Server-Sent Events (SSE). It does not write to Docker, execute commands in containers, or alter volumes or networks.
